# โปรแกรมถ่ายภาพสำหรับสร้าง Dataset บน Raspberry Pi

โปรแกรมนี้ใช้กล้อง Raspberry Pi แสดงภาพแบบเรียลไทม์ ตรวจจับวัตถุ และบันทึกภาพลงในโฟลเดอร์ย่อยภายใต้ `storage` โดยสามารถกำหนดชื่อไฟล์ส่วนหน้า (prefix) ได้จากหน้าต่างควบคุม โปรแกรมจะเติมเลขลำดับต่อท้ายชื่อให้อัตโนมัติ

## วิธีรันโปรแกรม

เปิด Terminal บน Raspberry Pi แล้วใช้คำสั่งต่อไปนี้:

```bash
cd /home/pi/Documents/CameraDataset
DISPLAY=:0 XAUTHORITY=/home/pi/.Xauthority .venv/bin/python ncnn_dataset_capture.py
```

เมื่อโปรแกรมเปิดขึ้น จะมีหน้าต่างภาพจากกล้องและหน้าต่างควบคุม

- พิมพ์ชื่อที่ต้องการในช่อง `Filename prefix`
- กด `Update Name` เพื่อใช้ชื่อใหม่
- กดปุ่มถ่ายภาพ หรือกด `Spacebar` เพื่อบันทึกภาพ
- กด `YOLO: ON/OFF` เพื่อสลับระหว่างตรวจจับวัตถุ กับเลือกกรอบครอปด้วยตนเอง
- กด `Full Frame: ON` เพื่อบันทึกเฟรมจากกล้องทั้งภาพที่ `640×480` โดยไม่ตรวจจับ ครอป หรือย่อภาพ
- เลือก `Manual crop` เพื่อกำหนดกรอบ `1:1`, `4:3`, `3:4` หรือ `224×244`
- เลื่อน `Crop size` เพื่อย่อหรือขยายกรอบโดยรักษาอัตราส่วนเดิม ไม่บีบภาพผิดรูป
- เลื่อน `Crop X` และ `Crop Y` เพื่อขยับกรอบในแนวนอนและแนวตั้ง หรือกด `Center Crop` เพื่อกลับมากึ่งกลาง
- กด `File Manager` เพื่อสร้าง เปลี่ยนชื่อ และเลือกโฟลเดอร์สำหรับบันทึก
- ถ้ามีวัตถุหลายชิ้น กด `n` เพื่อเลือกวัตถุถัดไป
- กด `Quit` หรือกด `q` ในหน้าต่างภาพเพื่อปิดโปรแกรม

ภาพจะถูกบันทึกไว้ที่:

```text
/home/pi/Documents/CameraDataset/storage/<ชื่อโฟลเดอร์>
```

ตัวอย่างชื่อไฟล์เมื่อกำหนด prefix เป็น `pill`:

```text
pill1.jpg
pill2.jpg
pill3.jpg
```

> ต้องคลิกหน้าต่างภาพจากกล้องก่อน จึงจะใช้ปุ่มลัด `Spacebar`, `n` และ `q` ได้

เมื่อ `YOLO: ON` โปรแกรมจะบันทึกภาพครอปของวัตถุที่ตรวจพบ หากไม่พบวัตถุจะไม่ถ่ายภาพ เมื่อ `YOLO: OFF` โปรแกรมจะแสดงกรอบครอปกึ่งกลางและทำพื้นที่ภายนอกให้มืด เพื่อให้จัดตำแหน่งวัตถุก่อนถ่ายได้ โดยมีขนาดให้เลือกดังนี้:

- `1:1` บันทึกเป็น `224×224`
- `4:3` บันทึกเป็น `224×168`
- `3:4` บันทึกเป็น `168×224`
- `Custom` บันทึกเป็น `224×244`

## การจัดการโฟลเดอร์และรูปภาพ

กดปุ่ม `File Manager` จากหน้าต่างควบคุม แล้วใช้งานดังนี้:

- `New Folder`: สร้างโฟลเดอร์ใหม่ภายใต้ `storage`
- `Use for Capture`: เลือกโฟลเดอร์ที่จะใช้บันทึกรูปถัดไป
- `Rename Selected`: เปลี่ยนชื่อรายการจากฝั่งที่คลิกเลือกล่าสุด หากเลือกรูปหลายรูปและกรอก `image` จะได้ `image1.jpg`, `image2.jpg`
- `Delete Selected`: ลบรายการที่เลือกจากฝั่ง Folder หรือ Images โดยถามยืนยันก่อน

รายการโฟลเดอร์และรูปจะอัปเดตอัตโนมัติ ไม่ต้องกด Refresh เมื่อเลือกรูปในรายการ รูปจะแสดงทางขวาโดยตรง หน้าต่างกล้องจะแสดงชื่อไฟล์ถัดไปและโฟลเดอร์ที่กำลังใช้งานอยู่ตลอดเวลา

ภาพใน File Manager จะแสดงด้วยขนาดพิกเซลจริงเมื่อพื้นที่เพียงพอ พร้อมข้อมูลชื่อไฟล์ โฟลเดอร์ ขนาดภาพ และขนาดไฟล์ใต้ภาพ

สามารถเลือกหลายรายการด้วย `Ctrl` หรือ `Shift` แล้วกดลบเฉพาะรายการที่เลือกได้ และสามารถคลิกขวาที่รูปหรือโฟลเดอร์เพื่อเปิดเมนูคำสั่งทั้งหมดของรายการประเภทนั้นได้ รายการใช้พื้นหลังสีขาวและเทาสลับกันเพื่อให้อ่านง่าย

## การส่งโฟลเดอร์ Storage ไปยัง MacBook

Raspberry Pi และ MacBook ต้องเชื่อมต่อเครือข่ายเดียวกัน และ Raspberry Pi ต้องเปิดใช้งาน SSH ก่อน

IP ปัจจุบันของ Raspberry Pi เครื่องนี้คือ `10.178.196.120` หากเชื่อมต่อไม่ได้ ให้ตรวจสอบ IP ใหม่บน Raspberry Pi ด้วย:

```bash
hostname -I
```

### วิธีที่ 1: ใช้ `scp` (วิธีง่าย)

เปิดแอป Terminal **บน MacBook** แล้วรัน:

```bash
scp -r pi@10.178.196.120:/home/pi/Documents/CameraDataset/storage ~/Desktop/
```

จากนั้นพิมพ์รหัสผ่านของผู้ใช้ `pi` เมื่อระบบถาม เมื่อเสร็จแล้วจะได้โฟลเดอร์ `storage` พร้อมโฟลเดอร์ย่อยทั้งหมดบน Desktop ของ MacBook

ในการเชื่อมต่อครั้งแรก ระบบอาจถามว่าเชื่อถือเครื่องนี้หรือไม่ ให้พิมพ์ `yes` แล้วกด Enter

### วิธีที่ 2: ใช้ `rsync` (แนะนำสำหรับไฟล์จำนวนมาก)

วิธีนี้เหมาะเมื่อมีรูปจำนวนมาก หรืออยากส่งเพิ่มในภายหลังโดยคัดลอกเฉพาะไฟล์ที่ยังไม่มีบน MacBook

เปิด Terminal **บน MacBook** แล้วรัน:

```bash
mkdir -p ~/Desktop/storage
rsync -av --progress pi@10.178.196.120:/home/pi/Documents/CameraDataset/storage/ ~/Desktop/storage/
```

เครื่องหมาย `/` หลัง `storage/` หมายถึงคัดลอกโฟลเดอร์และไฟล์ทั้งหมดที่อยู่ภายในไปยัง `~/Desktop/storage/`

### ตรวจสอบไฟล์หลังโอน

บน MacBook สามารถตรวจจำนวนรูปที่ได้รับด้วยคำสั่ง:

```bash
find ~/Desktop/storage -type f -name '*.jpg' | wc -l
```

คำสั่ง `scp` และ `rsync` ข้างต้นเป็นการคัดลอก จึงยังเก็บรูปต้นฉบับไว้บน Raspberry Pi หลังโอนเสร็จ

## หากเชื่อมต่อ SSH ไม่ได้

เปิด SSH บน Raspberry Pi ด้วย:

```bash
sudo raspi-config
```

จากนั้นเลือก `Interface Options` > `SSH` > `Enable` แล้วลองโอนไฟล์อีกครั้ง หาก IP เปลี่ยน ให้นำค่าจาก `hostname -I` มาแทน `10.178.196.120` ในคำสั่ง
